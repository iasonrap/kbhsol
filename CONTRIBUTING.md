# Contributing

Pull requests are welcome. A couple of things worth knowing first:

- This repo is under the [PolyForm Strict License](LICENSE) — per
  GitHub's Terms of Service, any content you submit to a repository is
  licensed under that repository's stated terms, so a PR you open here
  is contributed under the same license as the rest of the code.
- There's no build step — `python3 server.py` and open
  `http://localhost:8123`. See `CLAUDE.md` for the project's internal
  conventions (caching design, hardening rules, testing approach) before
  making a change.
- PRs are reviewed and merged at the maintainer's discretion.
